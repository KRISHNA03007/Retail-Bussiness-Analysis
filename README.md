# **Retail Business Analysis**
## 📌 Project Overview
This project focuses on **analyzing customer and sales data** to derive insights, clean the data, and prepare it for further analysis. The dataset included information about customers, purchases, product details, and transactions.

The main objectives were:  
- Data cleaning and preprocessing  
- Handling missing and duplicate values  
- Feature engineering and type corrections  
- Preparing the dataset for analysis 

## 🔹 Tools & Technologies Used:

- **Python**: Data Extraction, Data Cleaning
- **Excel**: Data exploration and creating structured templates
- **Power BI**: Interactive Analytics Dashboard for dynamic visualizations and insights

## 🔹 Key Data Cleaning & Transformation Steps
1. **Duplicate Removal:** Ensured data integrity by removing duplicate records  
2. **Missing Value Handling:**  
   - Filled missing `Date` values intelligently within the dataset range  
   - Ensured no critical information was lost  
3. **Data Type Correction:**  
   - Converted `Date` column to proper `datetime` format  
   - Converted all `float` numeric columns to `int`

- **Data Visualization:** Created plots to understand patterns using `matplotlib` and `seaborn`  
- **Power BI Dashboarding:** Built an **interactive analytics dashboard** to visualize key insights dynamically
